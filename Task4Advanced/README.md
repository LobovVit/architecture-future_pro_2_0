# Task4Advanced

## Ключевая идея
Целевая архитектура строится вокруг доменных контекстов, публикующих события через событийную платформу.  
Интеграция через события позволяет:
- снизить связанность между системами;
- упростить подключение новых направлений;
- перейти от batch и централизованных интеграций к near-real-time модели;
- убрать зависимость от DWH и Camel как центра всей бизнес-логики.
