# Технологический радар «Будущее 2.0»

Этот радар подготовлен для целевой архитектуры компании «Будущее 2.0».

## Фокус радара
- событийная архитектура;
- Data Mesh;
- self-service BI;
- governed data platform;
- постепенный вывод Camel и legacy DWH из критического пути.

## Интерпретация колец
- **Adopt** — использовать как стандарт;
- **Trial** — внедрять через пилоты;
- **Assess** — изучать точечно;
- **Hold** — не развивать как основу целевой платформы.
